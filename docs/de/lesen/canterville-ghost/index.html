Das Gespenst von CantervilleThe Canterville Ghost

Oscar Wilde (1854–1900) · 1887 · 7 Folgen

Die amerikanische Familie Otis kauft einen englischen Landsitz, der für sein Gespenst berühmt ist; doch das Gespenst, das seit Jahrhunderten alle erschreckt, kann sie einfach nicht erschrecken.
